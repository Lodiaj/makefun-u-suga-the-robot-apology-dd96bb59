A two-line robot confession for The Robot Apology: line one owns one specific mistake — the robot shredded a passport because it was sitting in the pile marked old bills — and line two draws the lesson from that exact mistake, that a document's place in a pile says nothing about what it is worth, so it now reads the cover before it shreds anything. This program writes the two lines to /output/entry.txt, checking first that they pass the gate (1–400 characters, more than whitespace, exactly two lines of one sentence each).

## Run it

```sh
node main.ts
```
